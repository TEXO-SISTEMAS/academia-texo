Implementá el sistema de autenticación completo usando Firebase Auth con Magic Link:

1. Configurar Firebase Auth en /lib/firebase.ts con el método de email link (Magic Link)
2. Crear el contexto de autenticación en /lib/auth-context.tsx que exponga:
   - usuario actual
   - rol del usuario (leído desde Firestore /users/{userId})
   - función sendMagicLink(email)
   - función logout()
   - estado loading
3. Crear la página /app/login/page.tsx con:
   - Campo de email
   - Botón "Enviar link de acceso"
   - Mensaje de confirmación después de enviar
   - Manejo del link de retorno (cuando el usuario vuelve del email)
4. Crear el middleware /middleware.ts que:
   - Proteja todas las rutas excepto /login
   - Redirija al Artesano a /artesano/dashboard
   - Redirija al Participante a /participante/dashboard
5. Crear la función en /lib/firestore.ts para crear el documento del usuario en Firestore al registrarse por primera vez (con role: 'participante' por defecto)
6. Crear las Firestore Security Rules básicas en firestore.rules
