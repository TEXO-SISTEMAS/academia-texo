Implementar autenticación sin contraseña usando Firebase Custom Tokens.

FLUJO:
1. Usuario pone su email en /login y hace clic en "Ingresar"
2. El frontend llama a /api/auth/verify con el email
3. La API route verifica en Firestore si el email está en 'allowedUsers'
4. Si NO está: retorna error 403 "Tu correo no está autorizado"
5. Si SÍ está: genera un Firebase Custom Token con el Admin SDK y lo retorna
6. El frontend usa signInWithCustomToken(auth, token) para autenticar
7. Redirige al dashboard según el rol

NUEVA API ROUTE /app/api/auth/verify/route.ts:
- Instalar: npm install firebase-admin
- Inicializar Firebase Admin con el mismo service-account.json que ya existe
- Leer email del body
- Verificar en Firestore colección 'allowedUsers' si existe documento con ese email
- Si existe: auth.createCustomToken(email, { role: userData.role })
- Retornar { token, role, name }
- Si no existe: retornar { error: 'not_authorized' }

CAMBIOS EN lib/auth-context.tsx:

  1. POST a /api/auth/verify con el email
  2. Si error: mostrar mensaje
  3. Si token: signInWithCustomToken(auth, token)
