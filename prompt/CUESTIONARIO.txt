Error al guardar cuestionario en Firestore:
"Function addDoc() called with invalid data. Unsupported field value: undefined"

El problema está en ResourceForm.tsx cuando construye el objeto quiz
para guardar — algunos campos de las preguntas quedan undefined.

Por favor en ResourceForm.tsx, antes de llamar a createResource/updateResource,
limpiar el objeto de preguntas del quiz:

1. Filtrar preguntas que tengan questionText vacío
2. Asegurar que cada pregunta tenga:
   - questionText: string (no undefined)
   - options: string[] con exactamente 4 elementos (reemplazar undefined por "")
   - correctIndex: number (default 0 si no está definido)
   - multipleChoice: boolean (default false si no está definido)
   - correctIndexes: number[] (default [] si no está definido)

3. Agregar esta función de limpieza antes del submit:
const cleanQuestions = questions.map(q => ({
  questionText: q.questionText ?? '',
  options: [
    q.options?.[0] ?? '',
    q.options?.[1] ?? '',
    q.options?.[2] ?? '',
    q.options?.[3] ?? '',
  ],
  correctIndex: q.correctIndex ?? 0,
  multipleChoice: q.multipleChoice ?? false,
  correctIndexes: q.correctIndexes ?? [],
}))

4. También en lib/firestore.ts, antes de cualquier addDoc o updateDoc,
   agregar una función que elimine todos los campos undefined del objeto:
const removeUndefined = (obj: Record<string, unknown>) => 
  Object.fromEntries(Object.entries(obj).filter(([_, v]) => v !== undefined))
