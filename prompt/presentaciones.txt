Para presentaciones tipo PPT/PDF subidas directamente a Drive necesito 
navegación real con botones Anterior/Siguiente.

La solución es crear una API route que convierta el PDF/PPT a imágenes 
usando la librería pdf2pic o similar, y mostrarlas como slides navegables.

Por favor:

1. Instalar dependencias: npm install pdf-to-img sharp

2. Crear /app/api/drive/slides/route.ts:
   - Recibe ?fileId=XXX
   - Descarga el archivo desde Drive usando la cuenta de servicio
   - Si es PDF: convierte cada página a imagen PNG usando pdf-to-img
   - Retorna array de URLs de imágenes base64 o las sube a Cloudinary 
     y retorna las URLs
   - Cachear el resultado en memoria (Map) para no reconvertir cada vez

3. En ResourceViewer.tsx para presentaciones con archivos subidos:
   - Al cargar el recurso, hacer fetch a /api/drive/slides?fileId=XXX
   - Mostrar las imágenes como slides con botones ← Anterior / Siguiente →
   - Mostrar spinner mientras convierte
   - Contador "Diapositiva X de Y"
   - Las imágenes deben ocupar el ancho completo del contenedor

Si la conversión falla o el archivo no es PDF, caer al iframe de Drive 
con mensaje de usar los controles nativos.
