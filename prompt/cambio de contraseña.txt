En /app/cambiar-contrasena/page.tsx el formulario aparece

Por favor:
1. Mostrá el código completo de la página
2. El error probable: signInWithCustomToken falla porque el token 
   ya fue usado o expiró (los custom tokens de Firebase expiran en 1 hora
   y solo se pueden usar una vez)
3. Solución: en lugar de hacer signInWithCustomToken de nuevo en esta página,
   usar el idToken que ya tenemos de Firebase Auth después del login exitoso
   
   El flujo correcto:
   a. En /api/auth/login-artesano, si forcePasswordChange es true:
      - Hacer signInWithPassword a Firebase REST API para obtener el idToken
      - Retornar { requiresPasswordChange: true, idToken, role, name }
   b. En /app/cambiar-contrasena/page.tsx:
      - Leer el idToken de sessionStorage (no el customToken)
      - Usarlo directamente en accounts:update para cambiar la contraseña
      - Sin necesidad de signInWithCustomToken en esta página

4. En sessionStorage guardar 'pendingIdToken' en lugar de 'pendingToken'
