Implementar login con contraseña para artesanos.

FLUJO NUEVO:
1. Usuario ingresa email → clic en "Continuar"
2. Sistema verifica en allowedUsers si el email existe
3. Si NO existe → "Tu correo no está autorizado"
4. Si existe y role === 'participante' → entra directo (igual que ahora)
5. Si existe y role === 'artesano' → aparece campo de contraseña
6. Artesano ingresa contraseña → clic en "Ingresar"
7. Sistema verifica contraseña contra Firebase Auth
8. Si correcta → entra al dashboard de artesano
9. Si incorrecta → "Contraseña incorrecta"

IMPLEMENTACIÓN:

1. En Firebase Auth hay que crear usuarios con email/contraseña 
   para los artesanos. Agregar instrucciones al final.

2. En /app/api/auth/verify/route.ts:
   - Si role === 'participante': comportamiento actual (custom token)
   - Si role === 'artesano': retornar { requiresPassword: true }
     NO generar el custom token todavía

3. Nueva API route /app/api/auth/login-artesano/route.ts:
   - Recibe { email, password }
   - Verifica que el email esté en allowedUsers con role: 'artesano'
   - Usa Firebase Admin para verificar la contraseña:
     adminAuth.getUserByEmail(email) → verificar que existe
   - Genera custom token si la contraseña es correcta
   - Para verificar contraseña usar Firebase Auth REST API:
     POST https://identitytoolkit.googleapis.com/v1/accounts:signInWithPassword
     con { email, password, returnSecureToken: true }
     usando NEXT_PUBLIC_FIREBASE_API_KEY
   - Si responde con idToken → contraseña correcta → generar custom token
   - Si responde con error → "Contraseña incorrecta"

4. En app/login/page.tsx:
   - PASO 1: solo campo email + botón "Continuar"
   - Si response.requiresPassword === true:
     mostrar PASO 2: campo contraseña + botón "Ingresar"
     con animación de aparición suave
   - Si response.token → signInWithCustomToken y redirigir

5. En allowedUsers, agregar campo password?: string NO — 
   la contraseña vive en Firebase Auth, no en Firestore
