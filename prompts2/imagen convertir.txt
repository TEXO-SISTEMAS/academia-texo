Para archivos DOCX y PPT/PPTX subidos como 'document' o 'presentation',
necesitamos convertirlos a PDF primero para poder mostrarlos como imágenes.

SOLUCIÓN: usar LibreOffice en Vercel via una imagen Docker personalizada.
Pero Vercel no soporta Docker en plan gratuito.

ALTERNATIVA REAL para Vercel gratuito:
Usar la API de Google Drive para convertir DOCX/PPT a PDF automáticamente.

Cuando el Artesano sube un DOCX o PPT:
1. El archivo se sube a Google Drive (ya funciona)
2. Llamar a Drive API para convertir a Google Doc/Slides format:
   POST /drive/v3/files/{fileId}/copy con mimeType correcto
3. Exportar como PDF:
   GET /drive/v3/files/{convertedFileId}/export?mimeType=application/pdf
4. Guardar el PDF en Drive y guardar ese fileId como pdfFileId en Firestore
5. En el viewer usar el pdfFileId para mostrar con pdfjs-dist

CAMBIOS NECESARIOS:

1. En /app/api/drive/upload/route.ts:
   Después de subir el archivo, si es DOCX/PPT/PPTX:
   - Convertir a Google Docs/Slides usando Drive API
   - Exportar como PDF
   - Subir el PDF a la misma carpeta del curso
   - Retornar tanto el fileId original como el pdfFileId

2. En types/index.ts:
   - DocumentContent y PresentationContent: agregar pdfFileId?: string

3. En ResourceForm.tsx:
   - Al recibir la respuesta del upload, guardar también el pdfFileId

4. En ResourceViewer.tsx:
   - Para 'document' y 'presentation': si tiene pdfFileId usar pdfjs-dist
   - Si no tiene pdfFileId (archivos viejos): mostrar iframe de Drive
