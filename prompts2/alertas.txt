Agregar diálogos de confirmación con advertencia antes de acciones destructivas
o importantes. Usar react-hot-toast para las confirmaciones visuales.

1. ANTES DE ELIMINAR (cualquier elemento):
Reemplazar el window.confirm() actual por un toast de confirmación custom:

Crear componente /components/shared/ConfirmToast.tsx:
- Muestra un toast con mensaje de advertencia en amarillo (texo-amarillo)
- Dos botones dentro del toast: "Cancelar" y "Confirmar" (en rojo)
- Uso: 
  toast((t) => <ConfirmToast t={t} message="..." onConfirm={() => ...} />, 
    { duration: Infinity, style: { background: '#31484E', color: 'white' } })

2. MENSAJES DE ADVERTENCIA por acción:

Eliminar propedéutico:
"⚠️ Esto eliminará el propedéutico y todo su contenido. No se puede deshacer."

Eliminar capítulo:
"⚠️ Esto eliminará el capítulo y todos sus recursos."

Eliminar recurso:
"⚠️ ¿Eliminar este recurso?"

Despublicar propedéutico:
"⚠️ Los participantes perderán acceso al propedéutico. ¿Despublicar?"

Eliminar contenido de La Academia:
"⚠️ ¿Eliminar este contenido? No se puede deshacer."

3. ACCIONES QUE NO necesitan confirmación (solo toast de éxito):
- Publicar
- Guardar/editar
- Crear
- Reordenar
