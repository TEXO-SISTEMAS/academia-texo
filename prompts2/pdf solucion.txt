Error en /api/drive/slides/route.ts:
"TypeError: Object.defineProperty called on non-object"

pdf-to-img usa pdfjs-dist que no es compatible con Next.js App Router RSC.

Solución: reemplazar pdf-to-img por una llamada directa a la API 
de Google Drive para exportar el PDF como imágenes.

Por favor:
1. Desinstalar pdf-to-img: npm uninstall pdf-to-img

2. En /app/api/drive/slides/route.ts, reemplazar la conversión con pdf-to-img
   por este approach usando la Google Drive API directamente:
   
   - Usar drive.files.export() con mimeType 'application/pdf' para descargar el PDF
   - Luego usar sharp para convertir cada página a PNG:
     npm install sharp (si no está instalado)
   
   Si sharp tampoco funciona en el entorno, usar este approach alternativo:
   - Retornar la URL de preview de cada página usando el parámetro de página de Drive:
     https://drive.google.com/file/d/FILE_ID/preview?page=N
   - Retornar un array de URLs (no imágenes base64) con una URL por página
   - El totalPages viene del campo content.totalPages del recurso
   - Si no tiene totalPages, retornar error indicando que el Artesano debe 
     ingresar el número de páginas

3. En ResourceViewer.tsx — PdfResource:
   - Si la API retorna URLs en lugar de base64:
     mostrar cada página como iframe con la URL correspondiente
     con overflow: hidden y scrolling: "no"
   - height: 600px por página, sin scroll
