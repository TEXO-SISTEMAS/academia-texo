El upload directo a googleapis.com desde el browser está bloqueado por CORS.
Necesitamos hacer el upload desde el servidor Next.js en chunks para evitar 
el límite de 4.5MB de Vercel.

Solución: Chunked upload via servidor propio.

1. Crear /app/api/drive/upload-chunk/route.ts:
   - Recibe: { chunk: base64, uploadUrl: string, start: number, total: number }
   - Hace PUT del chunk a la uploadUrl de Google Drive desde el servidor
   - Retorna: { done: boolean, fileId?: string }
   - Cada chunk máximo 4MB (bajo el límite de Vercel)

2. Actualizar lib/drive-upload.ts, función uploadVideoDirectToDrive:
   - Dividir el archivo en chunks de 4MB
   - Para cada chunk:
     a. Convertir a base64
     b. POST a /api/drive/upload-chunk con el chunk y la uploadUrl
     c. Actualizar barra de progreso
   - Al terminar todos los chunks: llamar a /api/drive/make-public
   - Mostrar progreso real: "Subiendo... X%"

3. El flujo completo:
   a. /api/drive/resumable-init → obtiene uploadUrl (ya funciona)
   b. Browser divide archivo en chunks de 4MB
   c. Por cada chunk: POST a /api/drive/upload-chunk (pasa por Vercel pero es pequeño)
   d. /api/drive/upload-chunk hace PUT parcial a googleapis.com (server-side, sin CORS)
   e. Al terminar: /api/drive/make-public

Nota: En Vercel el plan gratuito tiene timeout de 60 segundos por función.
Con chunks de 4MB y buena conexión debería funcionar.
Para videos muy grandes (>500MB) el proceso tarda varios minutos 
pero funciona porque son múltiples requests independientes.
