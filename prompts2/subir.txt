FLUJO COMPLETO:

1. Artesano selecciona un video en el panel
2. Frontend pide a /api/drive/resumable-init un "upload URL" firmada
3. La API route genera la URL de upload usando OAuth2 (server-side)
4. Frontend sube el archivo DIRECTAMENTE a Google Drive usando esa URL
5. Google Drive recibe el archivo, retorna el fileId
6. Frontend llama a /api/drive/make-public con el fileId para hacerlo público
7. Se guarda la URL en Firestore

PASO 1 — Obtener refresh token (necesario hacerlo una sola vez):

Crear /app/api/auth/oauth-callback/route.ts:
- Recibe el code de OAuth de Google
- Intercambia el code por access_token y refresh_token
- Muestra el refresh_token en pantalla (solo para setup inicial)

Crear /app/api/auth/oauth-url/route.ts:
- Genera la URL de autorización de Google OAuth2
- Scope: https://www.googleapis.com/auth/drive.file
- redirect_uri: http://localhost:3000/api/auth/oauth-callback

PASO 2 — API Routes del servidor:

/app/api/drive/resumable-init/route.ts:
- Recibe: { fileName, mimeType, fileSize, courseTitle }
- Usa el GOOGLE_OAUTH_REFRESH_TOKEN del env para obtener access_token
- Crea carpeta del curso en el Shared Drive si no existe
- Llama a la Drive API para iniciar un resumable upload:
  POST https://www.googleapis.com/upload/drive/v3/files?uploadType=resumable
  con los headers de autorización y metadata del archivo
- Retorna: { uploadUrl, folderId }

/app/api/drive/make-public/route.ts:
- Recibe: { fileId }
- Usa OAuth2 para hacer el archivo público (anyone reader)
- Retorna: { webViewLink, directLink }

PASO 3 — Frontend (lib/drive-upload.ts):

Crear función uploadVideoDirectToDrive(file, courseTitle, onProgress):
- Llama a /api/drive/resumable-init para obtener uploadUrl
- Sube el archivo directamente a uploadUrl usando XMLHttpRequest
  (para tener progreso real)
- Monitorea el progreso con xhr.upload.onprogress
- Al completar: llama a /api/drive/make-public con el fileId
- Retorna { fileId, webViewLink, directLink }

PASO 4 — ResourceForm.tsx:
- Para tipo 'video': usar uploadVideoDirectToDrive en lugar de uploadFileToDrive
- Para tipo 'presentation', 'pdf', 'document': mantener uploadFileToDrive 
  (pasan por Vercel, son archivos pequeños)
