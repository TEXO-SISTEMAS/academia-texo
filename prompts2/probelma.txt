El tracking de video sigue contando segundos cuando el usuario adelanta.
Necesito ver el código actual completo del componente de video en ResourceViewer.tsx.

Por favor:
1. Mostrá el código completo del componente que maneja el video
   (el que tiene onTimeUpdate, onSeeking, onSeeked)
2. Identificá exactamente dónde se agrega al Set watchedSeconds
3. El problema probable: onTimeUpdate se dispara durante el seek
   antes de que onSeeking se active

La solución más robusta:
- Guardar la posición ANTES del seek con onSeeking:
  const posBeforeSeek = useRef(0)
  onSeeking={() => { 
    posBeforeSeek.current = lastTime.current
    isSeeking.current = true 
  }}
  
- En onTimeUpdate verificar que el salto no sea mayor a 2 segundos:
  const diff = current - Math.floor(lastTime.current)
  if (diff > 2) {
    // Es un salto/seek, no agregar
    lastTime.current = e.currentTarget.currentTime
    return
  }
  if (!isSeeking.current) {
    watchedSeconds.current.add(current)
  }
  lastTime.current = e.currentTarget.currentTime
