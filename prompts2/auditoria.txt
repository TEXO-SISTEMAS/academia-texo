Implementar sistema de verificación de lectura/visualización antes 
de permitir completar un recurso.

1. ESTRUCTURA FIRESTORE — agregar a progress/{userId}/courses/{courseId}/resources/{resourceId}:
   - timeSpent: number (segundos totales que estuvo en el recurso)
   - pagesViewed: number[] (páginas del PDF que vio)
   - videoWatchedSeconds: number (segundos reales de video vistos, sin contar adelantos)
   - readingComplete: boolean (cumplió los requisitos para completar)
   - updatedAt: timestamp

2. VIDEOS — rastrear tiempo real visto (anti-adelanto):
   En ResourceViewer.tsx para tipo 'video':
   - Usar el elemento <video> con eventos: ontimeupdate, onseeked
   - Mantener un Set de segundos realmente vistos: watchedSeconds = new Set()
   - Cada segundo que el video reproduce normalmente: watchedSeconds.add(Math.floor(currentTime))
   - Si el usuario adelanta: NO agregar esos segundos al Set
   - Requerir que watchedSeconds.size >= duración * 0.9 (90% del video visto)
   - Mientras no cumpla: botón "Podés avanzar" deshabilitado con tooltip 
     "Debés ver el video completo antes de continuar"
   - Mostrar barra de progreso de visualización: "Visto: X% del video"
   - Guardar videoWatchedSeconds en Firestore cada 10 segundos (no en cada segundo)

3. PDFs — tiempo mínimo + todas las páginas:
   En ResourceViewer.tsx para tipo 'pdf':
   - Rastrear qué páginas vio: pagesViewed = new Set()
   - Al cargar cada página agregar al Set
   - Agregar botones ← Anterior / Siguiente → con navegación manual
   - Tiempo mínimo por página: 15 segundos (contador regresivo visible por página)
   - Mostrar: "Página X de Y — quedan Z segundos"
   - Solo habilitar "Siguiente página" cuando pasen los 15 segundos
   - Solo habilitar "Podés avanzar" cuando:
     * Vio TODAS las páginas (pagesViewed.size >= totalPages)
     * Pasó el tiempo mínimo en cada una
   - Guardar pagesViewed en Firestore cada vez que cambia de página

4. PRESENTACIONES — mismo sistema que PDF:
   - Tiempo mínimo por diapositiva: 10 segundos
   - Debe ver todas las diapositivas
   - Botones Anterior/Siguiente con contador regresivo

5. DOCUMENTOS de texto:
   - Tiempo mínimo total: 30 segundos en la página
   - Scroll hasta el final (detectar con IntersectionObserver en el último párrafo)
   - Mostrar barra de progreso de scroll: "Leído: X%"
   - Habilitar "Podés avanzar" cuando: tiempo >= 30s Y scroll al final

6. CUESTIONARIOS:
   - Sin cambios — ya requieren responder todas las preguntas

7. LOG EN FIRESTORE — función en lib/firestore.ts:
   updateResourceEngagement(userId, courseId, resourceId, data: {
     timeSpent?: number
     pagesViewed?: number[]
     videoWatchedSeconds?: number
     readingComplete?: boolean
   })
   - Usar merge: true para no sobreescribir datos anteriores
   - Solo guardar si readingComplete cambia a true o cada 30 segundos

8. PANEL DEL ARTESANO — mostrar en progreso:
   En /artesano/alumnos, al expandir un participante:
   - Mostrar tiempo total invertido en el propedéutico
   - Por recurso: tiempo visto, % de video visto, páginas leídas

9. UI — indicadores visuales mientras el participante consume el recurso:
   - Barra de progreso de consumo debajo del contenido (diferente a la barra de progreso del curso)
   - Color texo-amarillo mientras no completó los requisitos
   - Color texo-verde cuando cumplió y puede avanzar
   - Mensaje dinámico:
     * Video: "Visto: 45% — debés ver al menos el 90%"
     * PDF: "Página 2 de 5 — quedan 8 segundos en esta página"
     * Documento: "Leído: 60% — seguí bajando"
