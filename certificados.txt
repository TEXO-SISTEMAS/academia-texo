El certificado se ve bien en pantalla pero mal en el PDF descargado.

El problema está en cómo se genera el PDF con jsPDF.

Mostrame el código donde se genera el PDF (la función handleDownload o similar).

Probablemente está usando:
- jsPDF con dimensiones incorrectas
- O la escala del canvas no coincide con el PDF

La solución correcta es:

const handleDownload = async () => {
  const element = document.getElementById('certificate')
  if (!element) return
  
  // Capturar con html2canvas
  const canvas = await html2canvas(element, {
    scale: 2,
    useCORS: true,
    logging: false,
    backgroundColor: '#1a1a2e'
  })
  
  // Crear PDF con orientación landscape y tamaño correcto
  const pdf = new jsPDF({
    orientation: 'landscape',
    unit: 'px',
    format: [canvas.width, canvas.height]  // ← IMPORTANTE: usar dimensiones del canvas
  })
  
  // Agregar imagen al PDF con dimensiones exactas
  const imgData = canvas.toDataURL('image/png')
  pdf.addImage(imgData, 'PNG', 0, 0, canvas.width, canvas.height)
  
  pdf.save(`certificado-${courseName}.pdf`)
}
